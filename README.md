# 325 Overcreek
Concept site for 325 Overcreek Dr. Static HTML, deployed on Vercel.

- `index.html` – the site (desktop scroll-to-rotate, phone one-shot intro, touch-rotatable 3D model)
- `assets/frames` – 120 rotation frames with Huckleberry and the cat baked in behind the glass
- `assets/pets.js`, `assets/pets-frames.js` – the pets' idle animation and where they sit in each frame
- `assets/mobile` – phone intro video, poster, 3D model data and viewer
- `tools/` – scripts that build the model (`house.py`), render the frames, crop the drawings and build the pet data
